# BE-Addon-Studio-v4.0

> Modern Minecraft Bedrock Add-on Generator

BE Addon Studio is a web-based tool for creating Minecraft Bedrock Edition Add-ons without coding.

## ✨ Features

### Current

- 📦 Multiple Item Support
- 🖼️ PNG Texture Upload
- 📝 Manifest Generator
- 🆔 Automatic UUID Generator
- 💾 Local Project Save
- 📥 MCADDON Export
